# PLAYTEX AI

PLAYTEX AI builds browser-based texture and material workflow tools for game developers and 3D artists.

The PBR Map Generator uses deterministic image processing and procedural material generation. Separate AI-assisted tools can help create source imagery; those are distinct from map derivation.

## Public resources

- PBR export manifest and seven-map contract reference
- Map naming, color-space, and orientation guidance
- Explicit verification boundaries for package outputs and native destination claims

Visit [PLAYTEX AI](https://www.playtex.ai/).
